# IoT & Hardware Security

As a Control & Computer Engineering student, my approach to cybersecurity starts at the physical layer. This repository contains my research, labs, and documentation on securing and exploiting Operational Technology (OT), microcontrollers, and embedded systems.

## Objective
To bridge the gap between hardware engineering and cybersecurity by demonstrating practical attacks and defenses on physical devices, industrial control systems (ICS), and IoT infrastructure.

## Repository Structure
* **/UART-Exploitation:** Documentation, wiring diagrams, and scripts for interfacing with exposed serial ports on embedded boards.
* **/Firmware-Analysis:** Notes and methodologies for extracting, unpacking, and reverse-engineering device firmware.
* **/Arduino-Simulations:** Code (`.ino`) simulating vulnerable ICS/SCADA components and their secure counterparts.

## Technologies & Concepts
* Microcontrollers (Arduino, ESP32)
* Serial Protocols (UART, SPI, I2C)
* Logic Analyzers & Multimeters
* Firmware Reverse Engineering
